# Post-Quantum DICOM Provenance

Experimental research prototype for byte-preserving DICOM exchange using ML-KEM-768, HKDF-SHA-256, AES-256-GCM, ML-DSA-65, and witness-backed provenance.

**Not for clinical or production use.** Historical run artifacts are not fully reconciled with the currently available source. See `PROVENANCE.md` for limitations.
