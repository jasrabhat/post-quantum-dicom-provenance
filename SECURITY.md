# Security policy

This repository is an experimental research prototype, not a production security product. Do not open public issues containing patient data, private keys, credentials, or unredacted clinical artifacts.

This repository is not monitored as a guaranteed security-response channel. Until maintainers publish a dedicated contact method, use only general, non-sensitive project questions in public issues.

Known limitations include unresolved general signature-based duplicate-witness rejection, simulated/non-durable witnesses, rollback limitations, lack of full DICOM conformance, and a mismatch between the historical run's recorded harness hash and the available source.
